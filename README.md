# Биржа доверия — рабочее демо по PRD v3

Независимая реализация PRD v3 (24 страницы, с техническим заданием) для сравнения с основной веткой команды.
Стек из PRD v3: FastAPI + SQLite на бэкенде, React + Vite + TypeScript + Tailwind на фронтенде. Без Docker.
Внешний вид — по макету «Пул Биржи доверия».

## Запуск за 3 команды

Нужны Python 3.11+, [uv](https://docs.astral.sh/uv/) и Node 20+.

```bash
cd backend && uv venv -p 3.13 .venv && uv pip install -p .venv -r requirements.txt && .venv/bin/python seed.py
cd backend && .venv/bin/uvicorn app.main:app --port 8000
cd frontend && npm install && npm run dev      # http://localhost:5173
```

Claude необязателен. Без ключа объяснения собираются по шаблонам, а разбор правила продавца показывает поля для ручного ввода.
Чтобы включить Claude: `cp backend/.env.example backend/.env` и впишите ключ в `ANTHROPIC_API_KEY`.
`CLAUDE_MODEL` по умолчанию `claude-opus-5-5`. Бэкенд читает `.env` при старте; переменные из окружения важнее файла. `.env` в git не попадает.

Тесты: `cd backend && .venv/bin/python -m pytest -q`

## Демо-сценарий на 3 минуты

Перед каждым прогоном: меню «Еще» → «Сбросить демо» (или `POST /demo/reset`).

1. **Залог.** СтройПлюс (рейтинг 40) на лоте «Сахар белый» с правилом «от рейтинга 70» видит «вы не подходите» с причиной и вариантами. Переключение на цемент: залог 10% от 18 млн сум = 1,8 млн сум, до 6% осталось 20 баллов. Для сравнения ФерганаСтройСервис (92): 1% от 36 млн сум = 360 тыс. сум.
2. **Пул.** ИИ-пул из четырех участников на 90 т из 100: СтройПлюс 20 т, Бригада Алишера 25 т, Магазин Дилноза 30 т, МегаСтрой 15 т. Залоги 1,8 млн, 2,25 млн, 2,7 млн и 405 тыс. сум. ХорезмСтрой исключен: слишком далеко. Кнопки «Участвую» по очереди переводят пул в `locked`.
3. **Продавец.** Текст «не продавать новичкам больше 5 т и пускать от рейтинга 40» превращается в правило, продавец подтверждает. СомнительТрейд — отказ и высокий риск, Надежный Строй — допуск и низкий риск.

Остальные экраны в меню «Еще» статичные, на тех же данных: поиск с ценой до двери, поручительство, страховка и фонд, сделка и эскроу, журнал решений. Мини-аукцион (P2) не сделан: по PRD его режут первым.

## Как устроено

| Файл | Что внутри |
|---|---|
| `backend/app/config.py` | все условные числа: веса, ступени залога, лимиты, тарифы доставки, баллы риска |
| `backend/app/rating.py`, `deposit.py` | чистые формулы рейтинга, залога и страховки |
| `backend/app/pool.py` | подбор пула: фильтр, кластер 150 км, сумма подмножества, жадный маршрут |
| `backend/app/rules.py` | допуск по правилам продавца и оценка риска |
| `backend/app/ai.py` | Claude для трех задач и шаблоны на случай, если он недоступен |
| `backend/app/main.py` | API по разделу «API» PRD и журнал решений |
| `backend/seed.py` | идемпотентные демо-данные; рейтинги получаются из истории сделок по формуле |

ИИ предлагает, правила допускают, человек подтверждает: допуск, залог и рейтинг считает только код. Claude получает готовый JSON с результатом формулы и только объясняет его.

## Деплой на Vercel

Настроен в `vercel.json`: фронтенд собирается из `frontend/` в статику, FastAPI работает как Python-функция `api/index.py` по адресу `/api/*`.

- В настройках проекта Vercel → Environment Variables задайте `ANTHROPIC_API_KEY` (и при желании `CLAUDE_MODEL`). Файл `.env` на Vercel не попадает.
- База SQLite живет в `/tmp` функции и заполняется seed при первом запросе. Если функция уснет или Vercel запустит второй экземпляр, данные сбросятся к seed. Для показа демо это нормально; кнопка «Сбросить демо» работает как обычно.
