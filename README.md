# Davra — биржа доверия

Демо для хакатона UZEX 2035. Внешний вид — по макету Davra. Стек — по техзаданию PRD v3: FastAPI + SQLite на бэкенде, React + Vite + TypeScript на фронтенде.

Сценарий: пекарня «Non Uyi» пишет своими словами «2 т муки в/с в Самарканд». Биржа ставит ее в пул пекарен на вагон 60 т, считает задаток по рейтингу надежности, проводит торги продавцов, ведет сделку через эскроу и разбирает спор о недовесе.

## Запуск

Нужны Python 3.12+, [uv](https://docs.astral.sh/uv/) и Node 20+.

```bash
cd backend && uv venv .venv && uv pip install -p .venv -r requirements.txt
cd backend && .venv/bin/uvicorn app.main:app --port 8000
cd frontend && npm install && npm run dev      # http://localhost:5173
```

База и seed создаются сами при первом запросе. Кнопка «Сбросить демо» в боковой панели (или `POST /demo/reset`) возвращает все к началу.

Claude необязателен. Без ключа заявка разбирается правилами, а объяснение торгов собирается по шаблону. Экран честно пишет, когда ИИ недоступен.
Чтобы включить Claude: `cp backend/.env.example backend/.env` и впишите ключ в `ANTHROPIC_API_KEY`.

Тесты: `cd backend && .venv/bin/python -m pytest -q`

## Демо за 3 минуты

1. **Заявка.** «2 т муки в/с в Самарканд» (или по-узбекски «Samarqandga 2 tonna un»). ИИ-агент показывает заявку на языке биржи и находит пул из 36 покупателей.
2. **Пул и задаток.** Цена 4 260 сум/кг, на 18% ниже розницы. Задаток 2,5% = 213 000 сум вместо 10%, разбор по факторам рейтинга 82. «Внести задаток» — пул добирается до 60 т, 41 участник.
3. **Торги.** 6 раундов, ускоренно. Победил Zarafshon Don с 4 260 сум/кг, продавец с рейтингом 3,7 не допущен.
4. **Сделка.** Эскроу, затем «Получил, всё в порядке» — рейтинг 82 → 84, следующий задаток 2,3%.
5. **Спор** (вместо шага 4). «Открыть спор» — недовес 60 кг, возврат 255 600 сум. Решение принимает человек: «Принять» или «Передать арбитру».

## Откуда числа

Все деньги, задаток, рейтинг, итог торгов и решение по спору считает код в `backend/app/formulas.py`. Константы — в `backend/app/config.py`. Claude только разбирает текст заявки и пишет 4 пункта «как сложилась цена». Каждый пункт проверяет код: чужие числа, латиница не из входа и самоисправления заменяются шаблоном.

| Число | Формула |
|---|---|
| Рейтинг 82 | 7 за проверку в ГНК + 30 за 14 сделок + 25 за налоги 3 года + 25 за возраст 4 года − 5 за задержку в августе |
| Задаток 2,5% | 10% − баллы факторов / 10, в пределах 1–10% |
| 213 000 сум | 2,5% × 2 000 кг × 4 260 сум/кг, с округлением до 1 000 |
| 4 260 сум/кг | 4 390 (средняя биржевая за октябрь) × (1 − 3%), с округлением до 10 |
| 255 600 сум | (2 000 − 1 940) кг × 4 260 сум/кг |

Эскроу, банк, данные ГНК, распознавание голоса и ставки продавцов в демо — заглушки или seed. Голос записывается в браузере и распознается через [UzbekVoice.ai](https://uzbekvoice.ai) (узбекский и русский вперемешку). Ключ `UZBEKVOICE_API_KEY` хранится только на бэкенде, браузер шлет звук на `POST /stt`.

## Деплой: Vercel + Render (оба бесплатные)

**Бэкенд на Render.** New → Blueprint → этот репозиторий. Render прочитает `render.yaml` и спросит:
- `ANTHROPIC_API_KEY` — ключ Claude (можно оставить пустым, будут шаблоны);
- `UZBEKVOICE_API_KEY` — ключ распознавания голоса;
- `CORS_ORIGINS` — адрес фронтенда на Vercel, например `https://davra.vercel.app`.

Проверка: `https://<сервис>.onrender.com/health`.

**Фронтенд на Vercel.** Импортируйте репозиторий, корень — корень репозитория (настройки в `vercel.json`). В Environment Variables задайте `VITE_API_URL=https://<сервис>.onrender.com` и пересоберите.

Ограничения бесплатного Render:
- сервис засыпает через 15 минут без запросов, первый запрос будит его около минуты;
- при засыпании диск очищается, поэтому SQLite возвращается к seed;
- 750 бесплатных часов в месяц на workspace.

Перед показом откройте `/health` за пару минут, чтобы сервис проснулся.
